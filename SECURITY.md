# Security

Report suspected traffic leaks, authentication bypasses, unintended rule removal, or privilege issues through [GitHub's private vulnerability reporting](https://github.com/Vramuser/Hayase-BindVPN/security/advisories/new).

The repository owner must enable private vulnerability reporting in GitHub's security settings. If that form is unavailable, open an issue requesting a private reporting channel without including exploit details, pairing codes, credentials, or personal network information.

Include the helper/plugin versions, Windows version, adapter type, reproducible steps, and the results of any traffic checks. Do not assume a skipped or incomplete protection test verifies that traffic is protected.

The latest 1.x release is the supported version. Earlier development versions are superseded by 1.0.0.
