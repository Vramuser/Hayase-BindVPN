Hayase BindVPN 1.0.0 is the first public release for Windows x64. It adds an adapter selector and binding switch to Hayase, with a helper that blocks fallback traffic when the selected interface is unavailable.

### Included

- Adapter selection for Mullvad, WireGuard, OpenVPN, Proton VPN, and other VPNs with a system adapter.
- Persistent application blocking and temporary selected-interface exceptions.
- Automatic startup restoration and retries.
- Missing-Hayase warning and disabled activation.
- **Test protection** for rules, TCP/UDP connectivity, and blocked fallback.
- Tray opening, authenticated pairing, and targeted recovery.
- MIT-licensed source and SHA-256 checksums.

### Download

- **Hayase-BindVPN-Windows.zip** — complete helper, plugin, recovery, and setup guide. Recommended.
- **Hayase-BindVPN-plugin.zip** — plugin only; requires the matching helper.
- **Hayase-BindVPN-source.zip** — source for building and contributing.
- **SHA256SUMS.txt** — checksums for the three ZIP files.

Extract the Windows package, start its helper as administrator, import the plugin in Hayase, pair with its code, select the VPN interface, and enable binding.

### Update from a development version

Exit the old helper, start the new one, remove/re-import the plugin, and pair again. Your saved application and adapter selection are retained. Update both components together.

### Requirements and tested scope

Windows 10/11 x64, Hayase plugin support, a VPN system adapter, and administrator access. Keep the helper running while using Hayase.

Real IPv4 TCP/UDP restriction, recovery, startup logic, and extension checks passed. External IPv6 was not verified because the development host lacked an IPv6 internet route. Tests report skipped/incomplete checks. External players and separate system services are outside the Hayase.exe restriction.

See the repository README for installation, scope, testing, and recovery.
